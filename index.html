Retry after ambiguous response loss

Given a pinned tool-execution client and a synthetic non-idempotent action, when the response is deliberately dropped after the action completes, then the fixture records whether retry policy can produce a duplicate effect. Deliverable: replayable fixture, evidence report, and a focused patch only if justified.

Overlapping scheduler runs

Given two controlled runs of one pinned workflow, when their execution windows overlap, then exactly one downstream effect is recorded—or the report identifies the tested condition under which duplication remains possible. Deliverable: overlap fixture, evidence report, and rollback-safe patch when justified.
